# Seerr-docker

My docker compose for [Seerr](https://seerr.dev/).

## config folder

Required by seer as a docker volumes gives errors.

## .env example

```bash
SEERR_VERSION=version
DB_TYPE=postgres
DB_HOST=seerr-pg
DB_USER=seerr
DB_PASS=password
DB_NAME=seerr
POSTGRES_VERSION=version
POSTGRES_DB=seerr
POSTGRES_PASSWORD=Password
POSTGRES_USER=seerr
```
